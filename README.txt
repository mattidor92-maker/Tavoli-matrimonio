MINI SITO "TROVA IL TUO TAVOLO"

Contenuto:
- index.html  -> la pagina del sito
- guests.js   -> elenco invitati e tavoli

COME USARLO
1. Apri guests.js
2. Sostituisci i nomi di esempio con i tuoi invitati, mantenendo questo formato:
   { name: "Nome Cognome", table: "Tavolo 7" },
3. Salva il file.
4. Pubblica entrambi i file su un hosting statico:
   - Netlify
   - Vercel
   - GitHub Pages
5. Copia il link pubblico del sito.
6. Genera un QR code che punti a quel link.

NOTE
- La ricerca è esatta su nome e cognome, ma non fa differenza tra maiuscole/minuscole.
- Se vuoi, in una fase successiva si può aggiungere:
  - grafica matrimonio personalizzata
  - protezione con codice invitato
  - caricamento dati da CSV o Google Sheet
  - gestione di omonimi
